# 讲稿（每节一页）

每页的结构相同：

- **带走的一句话**：下课时学生应该能脱口而出的那句。
- **演示顺序**：45 分钟怎么分，先演示什么，在哪一格停下来。时间是建议值。
- **三个课堂提问**：附答案。都对应 Notebook 里的"停一下"或"预测"。
- **常见误解**：学生会在哪里想错，怎么纠正。
- **承上启下**：这一节接的是什么、为下一节留了什么。
- **课后作业与参考解**：Notebook 末尾练习的要点和关键代码。

上课前：

1. `source scripts/env.sh && bash scripts/run_all_notebooks.sh NN`（`NN` 是本节编号）确认这一节在你的机器上能跑完。
2. 讲课用 `notebooks/` 里**没有输出**的版本，逐格运行；每到"预测"先让学生举手表态再运行。
3. 没有真机时全程 `LIVE = False`。数据是合成的——讲到具体数值（足端力、温度、频率）时提醒学生"真机上不是这个数"。
4. 有真机时，建议每个 Part 留最后一节课做真机验证，按 `docs/real_robot_checklist.md` 逐项做并让学生记录。

| 节 | 主题 | 带走的一句话 |
|---|---|---|
| 00 | 环境与连接 | 连上 = 同一种 DDS + 同一个 Domain + 走对网卡 |
| 01 | 第一个订阅者 | 不 spin 就没有回调；阈值从数据里读 |
| 02 | struct 与 NumPy | 字节靠格式串，约定靠数据验证 |
| 03 | 线程与异步 | 一个慢回调会饿死所有回调 |
| 04 | Service / Action / TF | 一问一答用 Service，要花时间的事用 Action，坐标关系问 TF |
| 05 | SDK2 通道 | SDK 和 ROS 2 是同一条 DDS 总线上的两种说法 |
| 06 | Go2 SportClient | 返回 0 是"接受了"，不是"做完了" |
| 07 | Go2 LowState 分析 | 画原始曲线 → 定指标 → 找对照组 |
| 08 | Go2 桥接 | 桥写完先做重力检验 |
| 09 | G1 模式与行走 | G1 要先切对状态机；速度指令必须带时长 |
| 10 | G1 上肢 | 权重渐变、目标不跳、先回位再交还 |
| 11 | 低层关节控制 | τ = kp·Δq + kd·Δdq + τ_ff，三种现象一条式子 |
| 12 | G1 桥接与差异总表 | 相同的远比不同的多，不同的关在参数后面 |
| 13 | 控制节点与聚合节点 | 控制节点的默认输出是零 |
| 14 | 频率与延迟 | 频率、抖动、延迟是三件事，都要量 |
| 15 | Rosbag | 录完立刻 `ros2 bag info` |
| 16 | URDF / TF / 点云 | 图纸 + 关节角 = 每个连杆在哪 |
| 17 | SLAM 与 Nav2 | 地图只记录看到的 |
| 18 | 综合实验 | 链路可以全开着调，机器人一动不动，直到你打开开关 |
