# 07 · 走了五分钟，机器人身体里发生了什么？

**带走的一句话**：分析的套路是"画原始曲线 → 定指标或阈值 → 找一个本该相同的对照组"。

## 课堂提问

1. **RL 小腿电机最热，你怎么判断是它干得多还是它有毛病？**
   找对照组：四个小腿电机受力几乎一样（力矩平方均值相同），温升却差了一倍多。干的活一样而更热，说明是自身散热差或损耗大。
2. **步频是 2.5 Hz，机身 roll 晃动的主频也是 2.5 Hz，这是巧合吗？**
   不是。对角小跑时每一步支撑对角线切换一次，机身随之左右倾一下，所以晃动频率等于步频。
3. **为什么只取"站立不动"的时刻来看电压下降？**
   电压 = 开路电压 − 电流 × 内阻。走路时电流大且波动，电压被拉低且抖；站立时电流小而稳，电压变化才主要反映电量变化。

## 常见误解

- **"最热的电机就是有问题的电机。"** 也可能只是它负载最大。必须和负载对照。
- **"FFT 的峰就是步频，不用看图。"** 要先去均值（否则 0 Hz 最大），并确认片段里机器人确实一直在走。
- **"这些数值可以当 Go2 的参数用。"** 全部是合成的（电池是线性模型、温升系数是编的、异常电机是故意埋的）。要带走的是方法。把这句话说两遍。
- **"占空比 0.5 是普遍的。"** 是这段合成小跑的特征。真机不同步态、速度下不同。

## 课后作业与参考解

1. **`health_report`**：倾角最大值、`(power_v*power_a).mean()`、`soc[-1] / 每分钟耗电`、`GO2_JOINTS[argmax(temp[-1])]`；离群判据示例——同类电机（四个 hip / thigh / calf 各一组）中温升超过组内中位数 1.5 倍。
2. **前后受力比**：`foot_force[standing][:, :2].sum() / foot_force[standing][:, 2:].sum()`。合成数据里四脚均分（比值约 1）；真机通常偏前（头部和电池的位置）。
3. **现场采样**：`ChannelSubscriber("rt/lowstate", LowState_)` 存 10 秒的 `foot_force`，套本节的 FFT；注意采样率要用实测的到达频率，不能假定。
